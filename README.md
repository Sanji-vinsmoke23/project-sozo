# Project Sozo

An autonomous, immune-system-inspired Security Operations Center for containerized web applications.

## Directory Structure
- `src/`: Core implementation modules
- `tests/`: Unit, integration, and E2E evaluation suites
- `docs/`: Architecture diagrams and runbooks
- `scripts/`: Environment setup and lab management utilities

## Branches
- `main`: Production-ready releases
- `develop`: Primary integration branch
